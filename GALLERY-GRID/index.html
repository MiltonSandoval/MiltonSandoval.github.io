🎯 Cómo Funciona Este Grid

CSS Grid Con Auto-fit

.gallery {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 1.5rem;
}

/* ⭐ auto-fit: Crea tantas columnas como quepan
   ⭐ minmax(250px, 1fr): Mínimo 250px, máximo 1 fracción
   ⭐ Resultado: Responsive automático SIN media queries */

🔄 Auto-fit

Crea automáticamente el número de columnas que caben en el contenedor

📏 Minmax()

Define un tamaño mínimo (250px) y máximo (1fr) para las columnas

🎨 1fr

Fracción del espacio disponible - las columnas crecen uniformemente

📱 Sin Media Queries

Se adapta automáticamente a cualquier tamaño de pantalla
